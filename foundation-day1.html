Learn Fast Addition and Practice Quiz

तेजी से जोड़ना सीखें और प्रश्नोत्तरी से अभ्यास करें

बच्चों, नीचे दिये गये तरीकों को ध्यान से पढ़ें, इन तरीकों से आप बिना कॉपी और पेंसिल के ही सिर्फ अपने दिमाग मे बड़ी से बड़ी संख्याओं को तेजी से जोड़कर बता सकेंगे

Rule 1: दूसरी संख्या को तोड़कर जोड़ना)

Example 1

Addition of Two Digit Numbers: 36+27 = ?

First of all Break the second Number: 36+20+7

Now Add Second Number Tens with First Number: 36+20 = 56

Now Add Rest Number: 56+7 = 63

Result: 63

Remember : (Ones को जोड़ने के लिए हमेशा सबसे पहले Tens बनाते हैं और फिर बाकी बचे नंबर उसमे जोड़ देते हैं जैसे सबसे पहले देखेंगे कि 56 मे कितने नंबर 7 मे से जोड़ें कि 10 बन जाये, 56 मे 4 जोड़ने से 60 बनेगा, अब 7 मे से 4 निकालने पर बचे 3, तो अब इन 3 को 60 जोड़ने पर 63 उत्तर आएगा 13)

Example 2

Addition of Three Digit Numbers: 345+234 = ?

First of all Break the Second Number: 345+200+30+4

Now Add Second Number Hundreds: 345+200 = 545

Now Add Second Number Tens: 545+30 = 575

Now Add Second number Ones: 575+4 = 579

Result: 579

Example3

Addition of Three Digit Numbers: 3452 + 2136 = ?

First of all Break the second Number: 3452+2000+100+30+6

Now Add Thousands: 3452+2000 = 5452

Now Add Hundreds: 5452+100 = 5552

Now Add Tens: 5552+30 = 5582

Result: 5582

Rule 2: Compensation Method (समायोजन की विधि)

इस तरीके मे आप किसी संख्या को पास की आसान संख्या बनाइए, फिर जोड़िए और फिर पास की संख्या बनाने के लिए जितना अतिरिक्त जोड़ा था उसे घटा दीजिए।

Example 1: 49+36 = ?

Make 49 into 50 by adding 1

Now Add 50+36, Result = 86

Now Subtract the extra 1: 86-1, Answer = 85

Example 2: 298+145 = ?

Make 298 into 300 by adding 2

Now Add 300+145, Result = 445

Now Subtract the extra 2: 445-2, Answer = 443

Example 3: 3998+2475 = ?

Make 3998 into 4000 by adding 2

Now Add 4000+2475, Result = 6475

Now Subtract the extra 2: 6475-2, Answer = 6473
